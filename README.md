# 極雀 → 天鳳牌譜ビューア

[![License: CC0-1.0](https://img.shields.io/badge/License-CC0--1.0-blue)](./LICENSE)

極雀（旧 BigCoach）の AI 対戦牌譜を、[天鳳の牌譜ビューア](https://tenhou.net/5/)で局ごとに再生するための静的 Web アプリです。牌譜に記録されていない和了情報（役・符・翻・得点表示など）を、対局内容から判定できる範囲で補完します。

**公開ページ**: https://paifu.ka2kama.com

- 四人麻雀の牌譜専用です（三人麻雀には対応していません）
- 極雀・天鳳とは無関係の非公式ツールです
- 牌譜の解析・補完はすべてブラウザ内で完結し、サーバーには送信されません。外部にアクセスするのは、再生時に天鳳のサイトを新しいタブで開くときだけです

## 機能

- 牌譜 JSON の貼り付け読み込み・ファイル読み込み（`Ctrl / ⌘ + Enter` でも実行）・サンプル牌譜のワンクリック読み込み
- 局一覧の表示（局名・本場・和了 / 流局・和了者・ツモ / ロン・得点・役・補完の有無）
- 再生視点の固定（指定しない / 東家 / 南家 / 西家 / 北家）。極雀の牌譜でユーザー自身を表す `玩家` が一意にいる場合は、その対局者を初期選択します
- 天鳳の牌譜ビューアを新しいタブで開く / 再生 URL のコピー / 補完後 JSON のコピー
- 同名プレイヤーが複数いる牌譜（極雀では対戦 AI が全員 `AI` になる）は、起家順の番号で区別します（例: `AI①`）。画面表示・ビューア再生・コピーされる JSON で一貫し、全員固有名の牌譜には影響しません

## 入力形式

天鳳系ツールで広く使われる JSON 牌譜形式（通称 tenhou.net/6 形式）の生 JSON を受け付けます。

```json
{ "title": [...], "name": [...], "rule": {...}, "log": [...] }
```

天鳳の再生 URL の `#json=` に付く文字列は、この JSON を URL エンコードしたものです（中身は同じデータ。貼り付ける際はデコード済みのものを使います）。この構造であれば、極雀以外のツールが出力した牌譜も読み込めます。

## 補完の方針

元 JSON をなるべくそのまま使い、天鳳ビューアでの再生に不足している情報だけを補います。得点・役がすべて揃っている和了は補完せず、元データをそのまま表示・再生します。

| 区分 | 内容 |
|---|---|
| そのまま使用 | 配牌、ツモ、打牌、鳴き、立直記録、ドラ表示牌、開始点、点数差分 |
| 手牌から計算 | 和了形、役、符、翻、得点表示、ドラ、赤ドラ、裏ドラ（表示牌が元 JSON にある場合のみ） |
| 履歴から判定 | 一発、両立直、嶺上開花、槍槓、海底摸月、河底撈魚、天和、地和、九種九牌、四風連打、四家立直、四槓散了 |

- 履歴からの判定は、条件を明確に確認できる場合のみ行います
- 喰いタンは、ルール情報（`rule.disp` の「喰」/ `rule.kuitan`）があればその宣言に従い、情報がない牌譜では現代ルールの標準である「あり」として計算します

### 復元できないことがある情報

包の責任者、元 JSON に存在しない裏ドラ表示牌、宣言情報自体が失われている特殊ケース、三家和了の宣言有無は、確証がないため補完しません。

復元した役・得点が元 JSON の点差と一致しない場合は、**元 JSON の点差を優先**し、不一致であることを局一覧に表示します。元の点差を書き換えることはありません。

## 開発

### 構成

```text
gokujan-tenhou-viewer/
├─ public/
│  ├─ index.html   … アプリ本体（HTML / CSS / JS を含む単一ファイル）
│  ├─ img/         … 使い方のスクリーンショット
│  └─ sample.json  … サンプル牌譜（12 局）
├─ package.json    … wrangler と dev / deploy スクリプト
├─ wrangler.jsonc  … Cloudflare Workers Static Assets の設定
├─ LICENSE
└─ README.md
```

ビルドステップはありません。アプリのロジックは `public/index.html` の単一ファイルに収まっており、外部 CDN への依存もありません。

### ローカル実行

```bash
npm install
npm run dev
```

Wrangler の開発サーバーが起動し、表示された URL でアプリを確認できます。

### デプロイ

[Cloudflare Workers Static Assets](https://developers.cloudflare.com/workers/static-assets/) で配信しています。

```bash
npx wrangler login   # 初回のみ（ブラウザで Cloudflare にログイン）
npm run deploy
```

デプロイ先は Custom Domain の `https://paifu.ka2kama.com` です。workers.dev 側の URL は `wrangler.jsonc` の `workers_dev: false` で無効化しています。

### 開発方針

このリポジトリは意図的にフレームワークを使いません。

- React / Vue / Next.js への移植はしない
- バックエンド・DB・牌譜のサーバー保存は追加しない
- UI / 文言を目的なく変更しない
- 推測による情報補完を広げない
