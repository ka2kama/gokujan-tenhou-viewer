# 極雀 → 天鳳牌譜ビューア

極雀（旧 BigCoach）の AI 対戦牌譜 JSON を読み込み、不足している和了情報を可能な範囲で補完して、局ごとに[天鳳の牌譜ビューア](https://tenhou.net/5/)で再生する静的 Web アプリです。

入力は天鳳 JSON 形式（tenhou.net/6 形式）で、この形式であれば極雀以外のツールが出力した牌譜も読み込めます。**四人麻雀の牌譜専用**です（三人麻雀には対応していません）。

極雀・天鳳とは無関係の非公式ツールです。

## できること

- 牌譜 JSON の貼り付け / ファイル読み込み（`Ctrl / ⌘ + Enter` でも読み込み）
- 局一覧の表示（局名・本場・和了 / 流局・和了者・席・ツモ / ロン・得点・役・補完有無）
- 再生視点の固定（指定しない / 東家 / 南家 / 西家 / 北家）
- 天鳳の牌譜ビューアを新しいタブで開く
- 再生 URL のコピー / 補完後 JSON のコピー

`玩家` が一意に存在する場合は、その対局者を再生視点の初期値として選択します。

## 補完の方針

| 区分 | 内容 |
|---|---|
| そのまま使用 | 配牌、ツモ、打牌、鳴き、立直記録、ドラ表示牌、開始点、点数差分 |
| 手牌から計算 | 和了形、役、符、翻、得点表示、ドラ、赤ドラ、裏ドラ（表示牌が元 JSON にある場合のみ） |
| 履歴から判定 | 一発、両立直、嶺上開花、槍槓、海底摸月、河底撈魚、天和、地和、九種九牌、四風連打、四家立直、四槓散了 |

履歴からの判定は、条件を明確に確認できる場合のみ行います。

補完が働くのは和了詳細が不足している場合のみです。得点・役がすべて揃っている和了は、元データをそのまま表示・再生します（上書きしません）。

喰いタンは、ルール情報（`rule.disp` の「喰」/ `rule.kuitan`）があればその宣言に従い、情報がない牌譜では現代ルールの標準である「あり」として計算します。

### 復元できないことがある情報

- 包の責任者
- 元 JSON に存在しない裏ドラ表示牌
- 宣言情報自体が失われている特殊ケース
- 三家和了の宣言有無

確証がない情報は補完しません。復元した役・得点が元 JSON の点差と一致しない場合は、**元 JSON の点差を優先**し、不一致を局一覧に表示します。元の点差を書き換えることはありません。

## プライバシー

JSON の解析・補完・URL 生成はすべてブラウザ内で完結します。バックエンド・DB・保存 API・ログインはありません。牌譜がサーバーへ送信されることはありません。

再生時のみ、生成した URL で天鳳のサイトを新しいタブで開きます。

## 構成

```text
gokujan-tenhou-viewer/
├─ public/
│  └─ index.html   … アプリ本体（HTML / CSS / JS を含む単一ファイル）
├─ package.json
├─ wrangler.jsonc
└─ README.md
```

ビルドステップはありません。`public/index.html` が唯一の成果物で、外部 CDN への依存もありません。

## ローカル実行

```bash
npm install
npm run dev
```

Wrangler の開発サーバーが起動し、表示された URL でアプリを確認できます。

## デプロイ

[Cloudflare Workers Static Assets](https://developers.cloudflare.com/workers/static-assets/) へ配信します。

```bash
npx wrangler login   # 初回のみ（ブラウザで Cloudflare にログイン）
npm run deploy
```

デプロイ後は `https://paifu-viewer.<subdomain>.workers.dev` で公開されます。

独自ドメインを使う場合は、対象ドメインの zone が Cloudflare で有効であることを確認したうえで、`wrangler.jsonc` 内のコメントアウトされた `routes`（Custom Domain 設定）を有効化して再デプロイします。独自ドメインへの移行後は `workers_dev: false` で workers.dev 側の URL を無効化します。

## 開発方針

このリポジトリは意図的にフレームワークを使いません。

- React / Vue / Next.js への移植はしない
- バックエンド・DB・牌譜のサーバー保存は追加しない
- UI / 文言を目的なく変更しない
- 推測による情報補完を広げない
